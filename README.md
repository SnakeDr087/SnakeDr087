### ⚙️ How I build

- **Friction first.** The problem defines the tool, never the other way around.
- **Working and shippable beats elegant.** If it solves the problem in the field, it ships.
- **Own it.** If you can't back it up and run it without the vendor, you don't own it.
- I don't hand-write code. I build through structured context and methodology, and the tools carry the operational knowledge.
